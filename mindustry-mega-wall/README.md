# Мега-стена для Mindustry

Мод добавляет **Мега-стену 3×3**, которую нельзя убить. Все методы, которыми игра наносит урон зданию, у этой стены переопределены и ничего не делают, поэтому здоровье не падает. Снести её можно обычным способом, как любую стену.

- Категория в меню строительства: **Оборона** (Defense)
- Стоимость: титан 600, торий 400, пластан 200 (меняется в `src/main/java/megawall/MegaWall.java`)
- Здоровье показывается как 1 000 000, но урон не применяется вообще

## Установка на телефон (Android)

1. Скачай файл `dist/megawall.jar` на телефон (его можно взять из репозитория или получить от Claude).
2. В Mindustry открой **Моды** и импортируй файл `megawall.jar` (кнопка импорта в меню модов).
3. Перезапусти игру и убедись, что мод в списке модов включён.
4. Блок появится в меню строительства: **Оборона → Мега-стена**.

Нужна версия игры **160 или новее** (`minGameVersion: "160"` в `mod.hjson`). На более старой версии мод не загрузится.

## Установка на ПК

Тот же файл `megawall.jar` работает и на ПК: положи его в папку модов игры и перезапусти игру.

## Сборка

```bash
./build.sh
```

Скрипт скачивает Mindustry 160.7 (jitpack.io) и R8 с D8 (dl.google.com), компилирует мод и создаёт `dist/megawall.jar`. Требуется JDK 17 или новее, `curl` и `unzip`.

Картинка блока создаётся скриптом `tools/make_sprite.py`:

```bash
python3 -I tools/make_sprite.py src/main/resources/sprites/mega-wall.png
```

## Устройство

| Файл | Что делает |
| --- | --- |
| `src/main/java/megawall/MegaWallMod.java` | Точка входа мода: регистрирует блок. |
| `src/main/java/megawall/MegaWall.java` | Блок 3×3, стоимость и класс строения `MegaWallBuild`, который переопределяет все методы урона и `kill()`. |
| `src/main/resources/mod.hjson` | Метаданные мода. Поле `java: true` говорит игре, что внутри есть код. |
| `src/main/resources/sprites/mega-wall.png` | Спрайт 96×96: один симметричный блок без швов между тайлами. |
| `src/main/resources/bundles/` | Названия и описания на английском и русском. |
| `dist/megawall.jar` | Готовый мод. Содержит `.class` для ПК и `classes.dex` для Android. |

Почему один jar подходит и для ПК, и для Android: игра на ПК читает `.class`-файлы, а на Android ищет в корне jar файл `classes.dex`. `build.sh` добавляет его туда через D8.

## Проверка

- Мод загружен в headless-сервер Mindustry 160.7: блок зарегистрирован с размером 3×3, стоимостью из трёх ресурсов и здоровьем 1 000 000.
- Блок ставится на карту. Обычный, пробивающий, учитывающий броню и непрерывный (лазерный) урон, а также `kill()` не меняют здоровье. Обычная медная стена при таком же ударе погибает.
- Android: `classes.dex` собран D8 и проверен (заголовок, контрольные суммы, перечитывание D8). Загрузка на физическом телефоне не проверялась.

## Настройки

Всё меняется в `MegaWall.java`:

- `health` — число, которое видно в интерфейсе.
- `requirements(...)` — стоимость.
- `buildVisibility` — где блок показывается в меню.
