# Побег от чёрной дыры — 3D-игра на Python

Космический аркадный 3D-шутер от первого лица. Ты пилотируешь маленький корабль у чёрной дыры:
собери **12 энергоядер**, чтобы открыть **варп-врата**, и улети через них, пока дыра не утянула тебя.
Притяжение растёт каждую секунду, топливо ограничено, а вокруг летают астероиды.

Написана на [Ursina](https://www.ursinaengine.org/) (Panda3D). Графика и звуки создаются кодом —
никаких внешних файлов не нужно.

## Запуск

1. Установи Python 3.9 или новее: <https://www.python.org/downloads/>
2. В папке с игрой выполни:

```bash
pip install -r requirements.txt
python black_hole_escape.py
```

(На Windows можно `py -m pip install -r requirements.txt` и `py black_hole_escape.py`.)
Нужна видеокарта с поддержкой OpenGL 3.3+ (подойдёт любая из последних 10 лет, в том числе встроенная).

## Управление

| Клавиша | Действие |
|---|---|
| Мышь (или стрелки) | поворот корабля |
| W / S | вперёд / назад |
| A / D | влево / вправо |
| Пробел / C | вверх / вниз |
| ЛКМ (удерживать) | ускорение (тратит больше топлива) |
| Shift | тормоз |
| P или Esc | пауза |
| R | начать заново |

## Подсказки

- Голубой ромбик на экране показывает ближайшее ядро (а потом — врата) и расстояние до него.
- Двигатель тратит топливо, **а в космосе ты движешься по инерции** — разгонись и лети, не держа W постоянно.
- Каждое ядро даёт +30 топлива и немного щита.
- Следи за строкой «Притяжение»: когда она превышает тягу двигателя (15), загорается **ТОЧКА НЕВОЗВРАТА** —
  из неё уже не выбраться. Держись дальше от чёрной дыры.
- Тормоз (Shift) пригодится, чтобы остановиться возле ядра.

## Настройки

В начале `black_hole_escape.py` есть константы: сила притяжения `GM0`, её рост `GM_GROWTH`, тяга `THRUST`,
число ядер `CORES_TOTAL` и другие — подкрути, чтобы сделать игру легче или сложнее.
