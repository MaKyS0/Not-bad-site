# HBM Nuclear Tech для Minecraft Bedrock

Порт [HBM's Nuclear Tech Mod](https://github.com/HbmMods/Hbm-s-Nuclear-Tech-GIT) (Java, Forge 1.7.10) в виде аддона для Bedrock.
Текстуры и звуки взяты из оригинала, числа радиации — из его исходников (`HazardRegistry`, `HazmatRegistry`, `EntityEffectHandler`).

Нужен Minecraft Bedrock **1.21.90 или новее**. Экспериментальные функции включать не нужно.

## Установка

1. Скачайте `hbm-bedrock.mcaddon` и откройте его — Minecraft сам импортирует оба пакета.
2. В настройках мира: **Пакеты поведения** → включите *HBM Nuclear Tech (Bedrock) BP* (пакет ресурсов подключится сам).
3. Руды появляются только в **новых** чанках — отойдите подальше или создайте новый мир.

Собрать файл самому:

```bash
cd hbm-bedrock && npm install && npm run build
```

Результат — `hbm-bedrock/dist/hbm-bedrock.mcaddon`.

## Что уже есть (v0.1)

| Что | Как работает |
| --- | --- |
| Урановая, титановая, свинцовая руда | Генерация как в HBM: уран 7 жил по 5 блоков на высоте 8–25, титан 8×6 и свинец 6×9 на 8–35 |
| Слитки, блоки, урановые самородки | Переплавка руды в печи, крафт блоков и самородков |
| Радиация | Урановые предметы в инвентаре облучают: слиток 0,35 RAD/с, блок 3,5 RAD/с, умножается на количество |
| Лучевая болезнь | Пороги оригинала: 200 — тошнота и слабость, 400 / 600 / 800 — сильнее, с отравлением и иссушением, 1000 — смерть |
| Счётчик Гейгера | В инвентаре щёлкает (звуки HBM), в руке показывает дозу на экране, по нажатию — подробный отчёт |
| Костюм химзащиты | 4 предмета, снижает облучение на 75% (формула HBM: 10^−сопротивление) |
| Антирадин (RadAway) | Выводит 140 RAD за 7 секунд, оставляет пустой пакет |
| Рад-Икс (Rad-X) | +20% к защите на 3 минуты |

Рецепты упрощены: в оригинале нужны резина, микросхемы и бериллий, которых пока нет.

| Предмет | Рецепт |
| --- | --- |
| Ткань химзащиты ×2 | белая шерсть + свинцовый слиток + белая шерсть в ряд |
| Счётчик Гейгера | золотой слиток, медный слиток, 2 редстоуна, 5 титановых слитков |
| Пакет для капельницы ×4 | сушёная ламинария, железный слиток, сушёная ламинария (столбиком) |
| Антирадин | пакет + уголь + семена тыквы |
| Рад-Икс | 2 угля + кварц |

## Команды для проверки

```
/give @s hbm:geiger_counter
/give @s hbm:ingot_uranium 64
/scriptevent hbm:setrads 500
```

Последняя ставит вашу дозу (0–2500) — удобно, чтобы посмотреть стадии болезни.

## Чего пока нет

Машины, энергия, жидкости, реакторы, бомбы, оружие, радиация в чанках (заражённая местность). Это следующие шаги.
