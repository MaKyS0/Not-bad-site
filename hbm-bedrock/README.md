# HBM Nuclear Tech для Minecraft Bedrock

Порт [HBM's Nuclear Tech Mod](https://github.com/HbmMods/Hbm-s-Nuclear-Tech-GIT) (Java, Forge 1.7.10) в виде аддона для Bedrock.
Текстуры и звуки взяты из оригинала, числа — из его исходников (`HazardRegistry`, `HazmatRegistry`, `EntityEffectHandler`, `HbmWorldGen`, `TileEntityMachine*`).

Рядом лежит отдельный пакет **ClearLag** — аналог одноимённого серверного плагина против лагов.

Нужен Minecraft Bedrock **1.21.90 или новее**. Экспериментальные функции включать не нужно.

## Установка

Файлы из `dist/`:

| Файл | Что внутри |
| --- | --- |
| `hbm-bedrock-BP.mcpack` | HBM: поведение (блоки, предметы, скрипты) |
| `hbm-bedrock-RP.mcpack` | HBM: текстуры и звуки |
| `hbm-bedrock.mcaddon` | оба пакета HBM одним файлом |
| `clearlag.mcpack` | ClearLag, ставится отдельно |

На Android проще всего открыть файл **через Telegram**: отправьте его в «Избранное», нажмите на него и выберите Minecraft. «Мои файлы» на Samsung часто пишут, что открыть нечем.

Затем в настройках мира: **Пакеты поведения** → включите *HBM Nuclear Tech (Bedrock) BP* (пакет ресурсов подключится сам) и, если нужно, *ClearLag (Bedrock)*.

Руды появляются только в **новых** чанках.

Собрать файлы самому:

```bash
cd hbm-bedrock && npm install && npm run build
```

| Руда | Высота | Что даёт |
| --- | --- | --- |
| Урановая | 8–25 | слиток урана (радиоактивен) |
| Ториевая | 8–30 | слиток тория-232 (слабо радиоактивен) |
| Титановая | 8–35 | слиток титана |
| Свинцовая | 8–35 | слиток свинца |
| Вольфрамовая | 8–35 | слиток вольфрама |
| Алюминиевая | 8–45 | слиток алюминия |
| Бериллиевая | 8–35 | слиток бериллия |
| Серная | 8–35 | 2–4 серы |
| Селитровая | 8–35 | 2–4 селитры |
| Флюоритовая | 8–50 | 2–4 флюорита |

Руды металлов плавятся в обычной печи. В измельчителе каждая руда даёт **2 порошка**, а порошок плавится в слиток — так выходит вдвое больше металла. Это работает и для ванильного железа, золота и меди.

Сталь: железный порошок + угольный порошок → стальной порошок → переплавить.
Порох: 2 селитры + сера + уголь → 4 пороха.

## Механизмы

Энергия измеряется в HE, как в HBM. Машины соединяются **красным медным проводом** или просто ставятся вплотную друг к другу.

| Машина | Что делает | Энергия |
| --- | --- | --- |
| Дровяной генератор | жжёт уголь, древесину, палки, стержни ифрита | +100 HE за тик горения, буфер 100 000 |
| Электропечь | плавит руды, порошки, песок, еду и т.д. | 50 HE/тик, 5 с на предмет |
| Измельчитель | руда → 2 порошка, слиток → порошок, булыжник → гравий → песок | 5 HE/тик, 3 с на предмет |
| Аккумуляторный блок | запасает энергию, когда машины заполнены | 1 000 000 HE |

**Как пользоваться:**
- Нажмите на машину предметом — он загрузится (топливо в генератор, сырьё в печь или измельчитель).
- Нажмите пустой рукой или другим предметом — откроется окно с энергией, содержимым и кнопками «Забрать результат» / «Забрать загруженное».
- Чтобы поставить блок вплотную к машине, присядьте.
- Сломанная машина выбрасывает всё, что в ней было.

Энергия делится между машинами сети поровну, аккумуляторы заряжаются после того, как заполнены сами машины.

Рецепты (верстак):

| Предмет | Рецепт |
| --- | --- |
| Красный медный провод ×8 | свинец сверху и снизу, медь + редстоун + медь в середине |
| Дровяной генератор | 5 кирпичей вокруг печи, снизу медь + редстоун + медь |
| Измельчитель | железо, вольфрам, железо / поршень, редстоун, поршень / железо, медь, железо |
| Электропечь | 5 стальных слитков вокруг печи, снизу медь + блок редстоуна + медь |
| Аккумуляторный блок | свинец и алюминий по углам и краям, медь + блок редстоуна + медь в середине |

## Весь контент HBM и NTM Extended

Кроме машин и систем, сделанных вручную (ниже), в аддон автоматически перенесено содержимое обоих модов:

- **~2 080 предметов и ~700 блоков** с текстурами и русскими названиями из оригинальных языковых файлов: все слитки, самородки, порошки, заготовки, микросхемы, детали, инструменты, оружие, топливо, руды, блоки материалов, бетон и т. д. Из NTM Extended взято всё, чего нет в HBM.
- **Детали из материалов** (провода, болты, трубы, гильзы, литые и сварные пластины) — их текстуры окрашены по цветам материалов так же, как это делает HBM.
- **~1 400 рецептов верстака и печи** — все, у которых каждая деталь существует в аддоне.
- **Радиоактивность ~290 предметов** по таблицам HBM: урановые и плутониевые изотопы, топливо, отходы и т. д.

**Оружие HBM** (B93, Spark, HP, дефабрикатор, «Эвтаназия», «Стингер», «Скайстингер», криолятор, «Джек», иммолятор, двустволка, револьвер, «Соната», «Сатурнит», Folly, «Дампфмашина»): стреляют по нажатию, патроны — свои `…_ammo` из HBM; огнемёт поджигает, криолятор замедляет, ракетницы и Folly взрываются. Гранаты HBM бросаются и взрываются по типу.

Не ожили машины, чья работа держится на жидкостях, которых в аддоне нет (кислоты, газы, расплавы), и особые установки (циклотрон, лазер на свободных электронах, термояд, спутники) — они остаются блоками. Оружие нового поколения HBM существует только как 3D-модели без иконок и не перенесено. Не перенесено то, что Bedrock-аддон сделать не может или что не имеет текстуры в виде иконки: окна с ячейками, 3D-модели машин, жидкости в мире, новые измерения, шейдеры.

Импорт повторяется командой (нужны исходники обоих модов):

```bash
npm run import -- <путь к HBM> <путь к NTM Extended>
npm run build
```

## Жидкости и нефть

Жидкости (вода, пар, нефть, дизтопливо) идут по **трубопроводу** — так же, как энергия по проводу; машины, стоящие вплотную, соединяются и без трубы. В меню машины видно, сколько жидкости в её баках.

| Машина | Что делает |
| --- | --- |
| Водяной насос | 1000 mB воды в секунду за каждую сторону, касающуюся воды; энергии не нужно |
| Нефтяная вышка | качает нефть из залежи **прямо под собой** (500 mB раз в 2 с, 50 HE/тик); залежь со временем истощается |
| Нефтеперерабатывающий завод | 100 mB нефти → 60 mB дизтоплива в секунду, 50 HE/тик |
| Дизельный генератор | 10 mB дизтоплива → 2 500 HE в секунду |
| Цистерна | хранит 64 000 mB любой одной жидкости |
| Паровая турбина | пар → энергия (5 HE за 1 mB, до 2000 mB/с), конденсат отдаёт обратно водой |

**Нефтяные залежи** — большие тёмные карманы на высоте 10–40, примерно в каждом шестом чанке. Найти их помогает **нефтеискатель**: нажмите им, и он скажет, есть ли нефть под вами или рядом и на какой глубине.

## РБМК

Собирается из каналов, как в HBM. Нейтронный поток идёт от топливных каналов по 4 горизонтальным направлениям на 4 блока: другие топливные каналы на пути подхватывают его (это и есть цепная реакция), **каналы СУЗ** гасят его настолько, насколько опущены их стержни, **графитовые замедлители** усиливают. Поток греет каналы, тепло растекается к соседям, а **каналы-кипятильники** с водой превращают его в пар для турбин.

- Каналы: топливный (вставьте ТВС), СУЗ (стержень опускается по 25%), кипятильник (воду подайте насосом по трубе), замедлитель, пустой (конструкционный).
- Новые каналы СУЗ стоят полностью опущенными. Поднимайте их понемногу и следите за температурой.
- Кнопка **«АЗ-5»** в меню любого канала СУЗ опускает все стержни реактора разом.
- С 1200 °C — предупреждение, при **1500 °C реактор взрывается**: все каналы превращаются в обломки (держать их в руках смертельно), а вокруг на 150 блоков ложится долгое заражение.
- ТВС выгорает и превращается в отработанную; в измельчителе она даёт 9 самородков плутония.

Пример: топливо — СУЗ — топливо в ряд, к ним кипятильник, на кипятильник турбина, к кипятильнику труба от насоса в воде.

| Канал | Рецепт |
| --- | --- |
| Пустой канал ×4 | сталь по углам, 4 стальные пластины, графит в центре |
| Топливный | пустой канал + пустой стержень + свинцовая пластина |
| СУЗ | пустой канал + пустой стержень + вольфрам + микросхема |
| Кипятильник | пустой канал + 2 трубы |
| Замедлитель | пустой канал + 4 графита |

## Ракеты

1. Поставьте **стартовую площадку** и загрузите в неё ракету (собирается в сборочной машине).
2. Наведите **целеуказатель** на блок (до 256 блоков) и нажмите — цель запомнится.
3. В меню площадки нажмите **«Пуск»**.

Ракета летит от 3 до 30 секунд в зависимости от расстояния; место цели на время подгружается (ticking area), поэтому бить можно и туда, где никого нет. Фугасная — взрыв силой 15, зажигательная — 10 с пожаром, ядерная — как ядерный заряд.

## Реактор

**Исследовательский реактор** — генератор в той же сети HE, что и остальные машины.

- Загружайте **урановые топливные стержни** (до 8): нажмите на реактор стержнем.
- Новый реактор стоит с полностью опущенными управляющими стержнями (100%) и ничего не делает. В меню поднимайте их по 25%: чем выше, тем больше мощность и нагрев.
- Каждый работающий стержень даёт 2 500 HE/с и +5 °C в секунду. Охлаждает **вода вплотную к реактору**: каждая из 6 сторон в воде снимает 8 °C/с.
- 8 стержней на полной мощности безопасны, если в воде хотя бы 4 стороны. С 800 °C рядом появляется предупреждение, на **1000 °C — расплав**: взрыв, воронка и сильное заражение.
- Кнопка **«АЗ-5»** сразу опускает все управляющие стержни.
- Стержень выгорает за 20 минут полной мощности и превращается в **отработанный** — очень радиоактивный. В измельчителе он даёт 3 самородка **плутония-239**, а 9 самородков — слиток.

| Предмет | Рецепт |
| --- | --- |
| Пустой стержень ×2 | 3 стальных слитка столбиком |
| Урановый топливный стержень | пустой стержень + 3 урановых слитка |
| Исследовательский реактор | сталь по углам, 3 свинцовых блока (сверху и по бокам), блок редстоуна в центре, медь снизу посередине |

## Взрывчатка

Взводится **огнивом** (нажмите им на заряд) или **сигналом редстоуна** (рычаг, кнопка, провод рядом). Если сломать заряд во время отсчёта — он обезврежен. Заряд в чужом взрыве детонирует сразу.

| Заряд | Таймер | Взрыв |
| --- | --- | --- |
| Семтекс | 3 с | сила 8 (в 2 раза мощнее динамита) |
| Подрывной заряд | 3 с | сила 15 |
| **Ядерный заряд** | 10 с | воронка радиусом 40 блоков, вспышка, гриб, ударная волна и облучение до 80 блоков, мёртвая земля и обугленные деревья, радиоактивное заражение |

В HBM у ядерных бомб радиус 120–500 блоков, но телефон такое не потянет, поэтому здесь 40. Воронка выкапывается за несколько секунд и только в загруженных чанках.

Заражение после взрыва: в центре 20 RAD/с, к краю (80 блоков) падает до нуля, каждые 10 минут реального времени слабеет вдвое. Счётчик Гейгера его показывает, костюм химзащиты защищает.

| Заряд | Рецепт |
| --- | --- |
| Семтекс ×2 | селитра и сера по кругу, динамит в центре |
| Подрывной заряд | порох по углам, 4 динамита, редстоун в центре |
| Ядерный заряд | 4 слитка плутония-239 по углам, 4 подрывных заряда, стальной слиток в центре |

## ClearLag

Аналог плагина ClearLagg. Раз в 5 минут удаляет выброшенные предметы, сферы опыта и стрелы в загруженных чанках. Перед очисткой предупреждает в чате за 60, 30, 10 и 5 секунд. Предметы, выброшенные меньше минуты назад (например, после смерти), не трогает.

```
/scriptevent clearlag:tps
/scriptevent clearlag:now
/scriptevent clearlag:interval 600
/scriptevent clearlag:interval 0
```

`tps` показывает скорость сервера (20 — без лагов) и сколько каких сущностей загружено, `now` чистит сразу, `interval` задаёт период в секундах (минимум 30, `0` — выключить).

Улучшить FPS, как OptiFine или Sodium, аддон на Bedrock не может: движок отрисовки закрыт для аддонов. ClearLag снижает нагрузку на сам мир — меньше сущностей, меньше лагов.

## Для разработки

- `npm run generate` — пересоздаёт блоки, предметы, рецепты, генерацию руд и переводы из таблиц в `scripts/generate.mjs`.
- `npm run check` — проверка типов скриптов по API `@minecraft/server` 2.0.0 и сверка всех ссылок между файлами.
- `npm run build` — проверка и упаковка в `dist/`.

## Отличия от оригинала

Это упрощённый порт: машины — одиночные блоки вместо многоблочных моделей, меню вместо окон с ячейками, радиусы взрывов уменьшены под телефон, у многих рецептов меньше промежуточных деталей. Из крупного не перенесены ВВЭР, термоядерный и антиматериальный контент, химия (кислоты, газы) и космос.
